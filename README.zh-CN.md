# 黎曼ζ函数零点计算器

[English](./README.md) | [中文](./README.zh-CN.md)

一个用 Java 实现的黎曼ζ函数非平凡零点在临界线上的计算与验证程序。

## 项目概述

本项目计算并展示黎曼ζ函数 ζ(s) 的前10个非平凡零点，这些零点位于复平面上的临界线 Re(s) = 1/2。这些零点在数论中具有深远意义，尤其与黎曼猜想密切相关。

## 算法关键逻辑

### 1. 狄利克雷级数（直接求和）
当 Re(s) > 1 时：
```
ζ(s) = Σ(1/n^s)，n 从 1 到 ∞
```
实现中使用截断级数，包含 5000 项。

### 2. 函数方程
当 Re(s) ≤ 1 时，代码使用函数方程：
```
ζ(s) = π^(s-1/2) * Γ((1-s)/2) / ζ(1-s)
```
通过将临界带内的 ζ(s) 值与 Re(s) > 1 的值关联起来进行计算。

### 3. Gamma 函数近似
Gamma 函数 Γ(z) 使用斯特林公式和递推关系进行近似，以在函数方程中实现精确计算。

## 理论基础知识

### 黎曼ζ函数

黎曼ζ函数定义为复变量 s = σ + it 的形式：
```
ζ(s) = Σ(1/n^s) = 1/1^s + 1/2^s + 1/3^s + ...   （狄利克雷级数）
```
该级数在 Re(s) > 1 时收敛。

### 欧拉积（与素数的联系）

当 Re(s) > 1 时，ζ函数有等价的乘积形式：
```
ζ(s) = Π(1 - p^(-s))^(-1)   对所有素数 p
```
这建立了 ζ(s) 与素数分布之间的深刻联系。

### 临界带与临界线

- **临界带**：0 < Re(s) < 1
- **临界线**：Re(s) = 1/2（临界带的中心）

### 黎曼猜想

**ζ(s) 的所有非平凡零点都位于临界线 Re(s) = 1/2 上。**

这个未证明的猜想由伯恩哈德·黎曼于1859年提出，是千禧年大奖难题之一，证明或反证可获得100万美元奖励。

### 平凡零点与非平凡零点

- **平凡零点**：ζ(-2n) = 0，n = 1, 2, 3, ...（负偶整数）
- **非平凡零点**：所有其他零点，推测实部均为 1/2

## 算法实现原理

### 1. ζ函数求值策略

实现根据 s 所在的区域使用不同的方法：

```
如果 σ > 1:         直接狄利克雷级数求和
否则如果 σ > 0:     函数方程法
其他:               函数方程法（与上面相同）
```

### 2. 狄利克雷级数（σ > 1）

当 Re(s) > 1 时，级数绝对收敛：
```java
ζ(s) = Σ(n=1到N) 1/n^s
```

**实现**：截断至 N = 5000 项。更大的 N 提高精度但增加计算时间。

### 3. 函数方程（0 < σ ≤ 1）

对称形式：
```
π^(-s/2) Γ(s/2) ζ(s) = π^(-(1-s)/2) Γ((1-s)/2) ζ(1-s)
```

重新整理后用于计算 σ ≤ 1 时的 ζ(s)：
```
ζ(s) = π^(s-1/2) × Γ((1-s)/2) × ζ(1-s) / Γ(s/2)
```

**关键思想**：ζ(1-s) 的实部 Re(1-s) > 1，因此可以直接通过狄利克雷级数计算！

### 4. Gamma 函数近似

大 |z| 的斯特林近似：
```
Γ(z) ≈ √(2π) × z^(z-1/2) × e^(-z) × (1 + 1/(12z) + ...)
```

**实现**：
- 当 x < 0.5 时：使用反射公式 Γ(x)Γ(1-x) = π/sin(πx)
- 当 x ≥ 0.5 时：使用斯特林公式并通过递推减小参数

### 5. 零点搜索（未实现）

寻找零点需要：
1. **Gram 点**：满足 ζ(1/2 + i·g_n) 为实数的解（Gram 点之间符号交替）
2. **牛顿-拉弗森或二分法**：在 |ζ(1/2 + it)|² 上求根
3. **大规模计算**：使用 Odlyzko-Schönhage 算法等方法计算数十亿个零点

本实现存储已知零点而非计算它们，因为精确计算需要任意精度算术（通常需要50位以上十进制精度）。
